# Self-hosted candidate fonts

These WOFF2 files are self-hosted for the RAVEN font comparison
(`/public/font-test.html`). All are licensed under the SIL Open Font
License 1.1 (free for commercial use). Sources:

| File | Family | Source | License | Designer |
|------|--------|--------|---------|----------|
| `michroma.woff2` | Michroma (baseline) | Google Fonts — https://fonts.google.com/specimen/Michroma | OFL 1.1 | Ray Larabie |
| `librestile.woff2` | Librestile (Extended Bold) | https://github.com/ocelothe/Librestile | OFL 1.1 | ocelothe2k1 |
| `aldrich.woff2` | Aldrich | Google Fonts — https://fonts.google.com/specimen/Aldrich | OFL 1.1 | Ray Larabie |
| `exo2.woff2` | Exo 2 | Google Fonts — https://fonts.google.com/specimen/Exo+2 | OFL 1.1 | Natanael Gama |
| `oxanium.woff2` | Oxanium | Google Fonts — https://fonts.google.com/specimen/Oxanium | OFL 1.1 | Severin Meyer |
| `chakrapetch.woff2` | Chakra Petch | Google Fonts — https://fonts.google.com/specimen/Chakra+Petch | OFL 1.1 | Cadson Demak |

Librestile is a purpose-built libre equivalent of Microgramma / Eurostile /
Green Mountain 3 (inspired by Michroma). Google-hosted files were pulled from
the `fonts.gstatic.com` URLs in the Google Fonts CSS API (latin subset, weight 400).

This is a test harness only — not wired into the app. Once a winner is picked,
we'll keep just that font's file and remove the rest.
